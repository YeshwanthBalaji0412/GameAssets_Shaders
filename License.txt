--------------------------------------------------
ORIGINAL WORK IMPLEMENTED
--------------------------------------------------

The following work was implemented independently for this assignment:

Part A — Generative AI Assets:
• 10 novel game textures generated using Leonardo AI with ChatGPT-refined prompts
• Prompt engineering process including initial prompts, refined prompts, and
  comparison between manual and structured prompting approaches
• 5 storyboard frames visualizing the Chronos Zero gameplay sequence
• 2 original character designs (The Operative and Enemy Security Bot) with
  multiple views and prompt iteration documentation

Part B — Shader Deconstruction and Customization:
• Detailed video walkthrough explaining each node group in the M_RainDrops material
• RainSpeed parameter customization demonstrating drizzle (0.2), moderate (0.7),
  and storm (1.5) rainfall intensities
• Wetness intensity adjustments showing dry-to-soaked surface transitions
• Testing and demonstration across different lighting conditions
• Video narration script structure and shader explanation
